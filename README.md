# Solar App

Prototipo web de una plataforma de prevención del estrés térmico y cuidado personal mediante monitoreo ambiental, fisiológico y wearable.

## Estructura

- `index.html`: landing pública y punto de entrada para GitHub Pages.
- `login.html`, `register.html`, `recovery.html`: acceso y recuperación.
- `dashboard.html` y los módulos HTML restantes: monitoreo y prevención.
- `styles.css`: estilos globales del sitio.
- `solar-app.js`: estado simulado y lógica compartida.
- `assets/`: imágenes, iconos y fuentes locales.

## Ejecución

Abre `index.html` en un navegador o sirve la carpeta raíz con cualquier servidor estático. La aplicación utiliza `localStorage` para conservar el estado simulado del prototipo.
