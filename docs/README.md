# Solar

Landing page y panel preventivo de Solar, organizado para publicarse en GitHub Pages.

## Estructura

- `index.html`: entrada principal de la landing page.
- `assets/images/`: fotografías y recursos visuales.
- `assets/icons/`: favicon e iconos del sitio.
- `css/`: hojas de estilos de la landing, autenticación y dashboard.
- `js/`: comportamiento de la landing, autenticación y dashboard.
- `pages/`: login, registro y dashboard.

## Publicación

La página de inicio se encuentra en la raíz para que GitHub Pages la detecte automáticamente. Las rutas usan referencias relativas, por lo que funcionan tanto en un dominio propio como dentro de la URL de un repositorio.
